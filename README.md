# Server Room Monitoring System

An IoT-based server room monitoring system developed using NodeMCU ESP8266 and Arduino.

## Features

- Real-time temperature and humidity monitoring
- Gas and smoke detection
- Telegram notifications and status commands
- Audible alarm with mute/unmute functionality
- Temperature and humidity threshold alerts
- NTP-based time synchronization
- LCD status display
- LED indicators for normal and alarm states

## Hardware

- NodeMCU ESP8266
- DHT22 temperature and humidity sensor
- MQ-2 gas and smoke sensor
- 16x2 I2C LCD
- Buzzer
- Red and green LEDs

## Technologies

- Arduino C++
- ESP8266
- Wi-Fi and IoT
- Telegram Bot API
- NTP time synchronization

## Purpose

The project was designed to monitor environmental conditions in a server room and provide remote notifications when abnormal conditions are detected.
